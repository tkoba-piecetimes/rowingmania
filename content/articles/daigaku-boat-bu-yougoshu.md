大学ボート部（漕艇部）の入部直後と観戦で出てくる用語を、7分類で一覧にしました。英語由来の言葉と日本語の訳語が混在して戸惑いやすいため、各用語を一言で説明しています。ボートの知識がない状態からでも、必要な用語から順に引けます。

## 大学ボート部の用語がわかりにくい理由

大学ボート（漕艇）の用語がわかりにくいと感じられる理由は、英語由来の専門用語と日本語の訳語が併用されていることに加え、検索してもボートレース（競艇）の情報と混ざりやすいためです。

入部直後は、「キャッチ」「フィニッシュ」「レート」といった動作用語と、「m1x」「w8+」のような種目コード、さらに「決勝A」「敗者復活戦」といったレース進行の表記が短期間にまとめて登場します（いずれも本記事で順に説明します）。用語の性質がそれぞれ異なるため、どこから覚えればよいのかつかみにくくなりやすい構造だといえます。初めて観戦する場合も、大会のプログラムやアナウンスに出てくる略号やカタカナ語が何を指しているのかは、事前に知らなければ判断しづらい部分です。

この記事では、編集部が実際の用語集・入門ページ・大会結果ページの表記をもとに、用語を次の7分類に整理しました。

- 漕ぎの動作に関する用語（キャッチ・ドライブ・フィニッシュなど）
- 艇と道具に関する用語（ブレード・リガー・シェル艇など）
- 乗艇ポジションと乗り方に関する用語（コックス・ストローク・スカル・スイープなど）
- 練習中の号令・掛け声（さあ行こう・イージー・オールなど）
- 種目コードの読み方（m1x・w8+など）
- レース進行の表記（予選・敗者復活戦・決勝Aなど）
- 大会・審判の用語と記録表記（DNS・DNFなど）

なお、「ボート」という単語だけで検索すると、公営競技であるボートレース（競艇）に関する情報が上位に表示されやすい点にも注意が必要です。本記事で扱うのは大学の部活動としての漕艇（ローイング）であり、賭け事としてのボートレースとは別の競技です。

## 漕ぎの動作に関する用語

漕ぎの一連の動きには、それぞれ決まった呼び方があります。基本となる用語は次のとおりです。

| 用語 | 意味 |
|---|---|
| キャッチ | オールのブレードを水に入れ、水をつかむこと |
| ドライブ | キャッチから水を押し終わるまでの、艇を進める局面 |
| フィニッシュ | ストロークの最後。水を押し終わり、ブレードが水上に出た直後のこと |
| フォワード | フィニッシュから次のキャッチまでの、ハンドルを前に戻す局面 |
| フェザー | ブレードを水平にすること。フォワード中の空気抵抗や波の影響を抑えるために行う |
| スクエア | フェザーの逆で、ブレードを水面に対して垂直に立てること。キャッチに備える動作 |
| レート（ピッチ） | 1分間に漕ぐストロークの回数 |
| スパート | レース終盤などにレートを上げて加速すること |
| イージー | ブレードを水面に落として漕ぐのをやめ、休息に移ること |

1回のストロークは、キャッチで水をつかみ、ドライブで艇を進め、フィニッシュで水を押し終え、フォワードでハンドルを前に戻す、という一連の流れで構成されています。この流れが連続して繰り返されることで艇は前進します。フォワード中はフェザーでブレードの抵抗を減らし、次のキャッチの直前にスクエアへ戻す、という動作もあわせて覚えておくと、練習中の指示や解説の意味がつかみやすくなります。東郷町の用語集では、フィニッシュ後に上体を前傾させる動作を「リカバリー」と呼んでいます（図中の表記）。

## 艇と道具に関する用語

艇本体やオールにも、それぞれ専用の呼び方があります。

| 用語 | 意味 |
|---|---|
| ブレード | オールの水をつかむ平たい部分 |
| クラッチ | オールの支点となる台座 |
| リガー | 艇の側面から張り出し、クラッチを支える骨組み |
| ストレッチャー | 漕手が足をかける踏み板。シューズが固定されている |
| シート | レール上を前後に動く座席。脚の伸展に合わせてスライドする |
| リギング | 艇やオール、シート、ストレッチャーなどの配置・角度を漕手に合わせて調整すること |
| シェル艇 | レース用の細長い競技艇 |
| ナックル艇 | 船体の断面が拳のような形をした、安定性を重視した艇。初心者向けに開発された |
| エルゴメーター（エルゴ） | 陸上で漕ぐ動作を再現するトレーニング機器。タイム計測にも使われる。使い方は[エルゴの使い方](../rowing-ergo-tsukaikata-shoshinsha-guide/index.html)で解説 |
| ハンドル（グリップ） | オールの手で握る部分 |
| ラダー | 艇の進路を操作する舵の装置 |
| バウボール | 艇首に付ける直径4cm以上の白いボール。安全のために取り付ける（JARA定義） |
| ポンツーン | 乗り降り用の浮桟橋など（JARA定義） |
| 艇庫 | 艇を収容する倉庫（ボートハウスとも） |
| ウマ（船台） | 艇を載せておく台 |

このうちリギングは、艇やオールの各部を漕手の体格・技術に合わせて調整する作業を指し、同じ艇でも乗る人によって設定が変わります。またナックル艇は、レース用のシェル艇に比べて安定性を重視した形状で、初心者向けに開発された艇です（出典: [東郷町「用語集 - ボート」](https://www.town.aichi-togo.lg.jp/soshikikarasagasu/shogaigakushuka/gyomuannai/2/3/2424.html)）。陸上で漕ぐ動作を再現するエルゴメーターとあわせて、どの道具がどの場面で使われるものなのかを整理しておくと、入部初期の練習メニューの意図をつかみやすくなります。オールを1人何本持つかで分かれる艇の種類については、[スカルとスイープの違い](../scull-sweep-chigai-daigaku-boat/index.html)で解説しています。<!-- index-lane-link -->

## 乗艇ポジションと乗り方に関する用語

艇に乗る役割や、オールの持ち方による分類にも専用の呼び方があります。

| 用語 | 意味 |
|---|---|
| コックス（舵手） | 舵の操作と漕手への指示を行い、艇の動きを管制する役割 |
| 漕手 | オールを漕ぐ人 |
| ストローク（整調） | 最も艇尾寄りに座り、クルー全体の漕ぐリズムをつくる漕手。役割は[ストローク（整調）の役割](../boat-bukatsu-stroke-position-yakuwari/index.html)で解説 |
| バウ | 艇の先端、またはそこに近い位置に座る漕手 |
| ストロークサイド／バウサイド | 整調が漕ぐ側／バウが漕ぐ側（左右どちらにあたるかは資料によって説明が異なる） |
| バウペア／ストロークペア | バウペアはバウと2番の漕手の組み合わせ。ストロークペアはエイトなら7番と整調、フォアなら3番と整調の組み合わせ |
| 艇身・艇差 | 艇差は競漕中の2艇の距離の差。艇身はその単位で、後続艇の艇首が先行艇の艇尾と同じ位置にあるとき1艇身 |
| バウナンバー | 艇首に取り付ける艇の番号（JARA定義） |
| クルー | 1艇に乗るメンバーのまとまり |
| レガッタ | ボートの競技会・大会のこと |
| スカル | 1人が左右に1本ずつ、計2本のオールを持つ様式。またその艇 |
| スイープ | 1人が1本のオールを持つ様式。またその艇 |
| 舵手つき・舵手なし | コックスが乗るかどうかの区別 |

「ストローク」という言葉は、艇の最後尾に座ってリズムをつくる漕手のポジション名として使われる場合と、漕ぐ動作そのものを指す場合の両方があるため、文脈によって意味が変わる点に注意が必要です。また「バウ」（先頭付近の漕手を指すポジション名）と「バウナンバー」（艇首に取り付ける艇の番号）は似た言葉ですが、指す対象が異なります。

コックスとストローク、スカルとスイープはいずれも奥が深いテーマのため、詳しい役割や違いは別記事で詳しく解説しています。あわせて[スカルとスイープの違い](../scull-sweep-chigai-daigaku-boat/index.html)、[コックスとは](../boat-bukatsu-cox-towa/index.html)をご覧ください。

## 練習中の号令・掛け声

練習中には、動作の開始や停止を知らせる独特の号令が使われます。部によって言い回しが異なる場合があるため、ここでは東郷町の用語集に掲載されている定義を紹介します（出典: [東郷町「用語集 - ボート」](https://www.town.aichi-togo.lg.jp/soshikikarasagasu/shogaigakushuka/gyomuannai/2/3/2424.html)）。

| 用語 | 意味 |
|---|---|
| さあ行こう | 漕ぎ始めや動作を変えるときの号令の一つ |
| 用意して | 漕ぎ始めの準備を指示する言葉 |
| ありがとう | 各種動作を止める指示 |
| イージー・オール | 漕ぎを止め、ブレードを水平にして休息の姿勢をとること。またその指示 |
| バックロー | 逆方向に漕いで、艇を後退させること |
| ストップロー | 水中でブレードを垂直にして、艇を止めること |
| パドル | コンスタントと同じ意味 |
| ライトパドル | パドルとノーワークの中間の速さで漕ぐこと |
| コンスタント | レースで基本となる速度、およびその速度を保つ漕ぎ方 |
| スパート | コンスタント以上の速さで漕ぐこと |
| 乗艇 | 艇に乗ること。乗って練習することも含む |
| 沈・落水 | 沈はボートが沈没すること。落水は漕手や舵手が水中に落ちること |

「ありがとう」は感謝の言葉としてではなく、動作を止める指示として使われる点が初見では戸惑いやすい部分です。実際の運用は部やコーチによって異なる場合があるため、入部後は先輩の説明もあわせて確認してください。

## 種目コードの読み方｜m1x・w8+ は何を表すか

大学ボートの大会結果では、種目名が「m1x」「w8+」のようなアルファベットと記号の組み合わせで表記されます。この種目コードは、次のルールで構成されています。

- 先頭のアルファベット：m（男子）または w（女子）
- 数字：漕手の人数
- x の有無：x がつく場合はスカル（1人2本のオール）、つかない場合はスイープ（1人1本のオール）
- 末尾の記号：+ はコックス（舵手）が乗る、- はコックスが乗らないことを示す

![種目コードの読み方（m8+は男子エイト）](diagram:rowing-event-codes)

このルールに沿って15種の種目コードを一覧にすると、次のとおりです。

| コード | 種目名 | 漕手 | オール | コックス |
|---|---|---|---|---|
| m1x | 男子シングルスカル | 1人 | スカル | なし |
| m2x | 男子ダブルスカル | 2人 | スカル | なし |
| m4x | 男子舵手なしクォドルプル | 4人 | スカル | なし |
| m2- | 男子舵手なしペア | 2人 | スイープ | なし |
| m2+ | 男子舵手つきペア | 2人 | スイープ | あり |
| m4- | 男子舵手なしフォア | 4人 | スイープ | なし |
| m4+ | 男子舵手つきフォア | 4人 | スイープ | あり |
| m8+ | 男子エイト | 8人 | スイープ | あり |
| w1x | 女子シングルスカル | 1人 | スカル | なし |
| w2x | 女子ダブルスカル | 2人 | スカル | なし |
| w4x | 女子舵手なしクォドルプル | 4人 | スカル | なし |
| w4x+ | 女子舵手つきクォドルプル | 4人 | スカル | あり |
| w2- | 女子舵手なしペア | 2人 | スイープ | なし |
| w4+ | 女子舵手つきフォア | 4人 | スイープ | あり |
| w8+ | 女子エイト | 8人 | スイープ | あり |

この15種は、ローイングマニアが収録している全日本大学ローイング選手権（インカレ）2000年度〜2025年度の結果データに、通算で登場した種目コードのすべてです。ただし、すべての年度でこの15種が実施されているわけではなく、年度によって実施種目は増減します。同じ集計では、男子舵手つきペア（m2+）は2000年度から2018年度までの結果に登場する一方、女子エイト（w8+）は2023年度から2025年度の3年度分にとどまります。古い年度の結果と最近の結果を並べて見るときは、種目そのものの実施有無が変わっている場合がある点を意識しておくと、読み違いを防げます。

種目コードの表記は、JARA公式のレース結果ページでもローイングマニアの結果ページでも共通して使われているため、一度読み方を覚えておくと大会結果を見るときにスムーズです。各種目の歴代優勝校は、[種目一覧ページ](../../events/index.html)からまとめて確認できるほか、[男子エイト（m8+）の歴代優勝校ページ](../../events/m8+/index.html)、[男子シングルスカル（m1x）の歴代優勝校ページ](../../events/m1x/index.html)、[女子舵手つきクォドルプル（w4x+）の歴代優勝校ページ](../../events/w4x+/index.html)、[女子エイト（w8+）の歴代優勝校ページ](../../events/w8+/index.html)でそれぞれ確認できます。

## レース進行の用語｜予選・敗者復活戦・決勝Aの意味

大学ボートの大会は、複数のラウンドを経て順位が決まります。JARAの結果ページでは、それぞれのラウンドが次のように日本語と英語で表記されています。

| 日本語表記 | JARA結果ページの英語表記 | 内容 |
|---|---|---|
| 予選 | Heat | 最初に行われる組分けレース。上位が次のラウンドへ進む |
| 敗者復活戦 | Repechage | 予選で勝ち上がれなかったクルーにもう一度与えられる機会 |
| 準々決勝 | Quarter finals | 出場クルーが多い種目で準決勝の前に設定されるラウンド |
| 準決勝 | SemiFinal | 決勝の組分けを決めるラウンド |
| 決勝A | Final A | 最上位の決勝。優勝クルーはこのレースで決まる |
| 決勝B | Final B | 決勝Aに進めなかったクルーによる、下位の順位を決める決勝 |
| 決勝C・D・E | Final C / D / E | 出場クルーがさらに多い場合に設定される下位決勝 |

この中で特に間違えやすいのが「決勝A」です。決勝は複数組に分かれますが、優勝を決めるのは決勝Aのみであり、決勝B以下は下位クルー同士の順位を決めるレースです。決勝という言葉だけを見て「決勝に出た＝優勝を争っている」と早合点しないよう、注意が必要です。

![勝ち上がりの流れの一例（予選・敗者復活戦・準決勝・決勝A/B）](diagram:rowing-race-rounds)

ローイングマニアが2000年度〜2025年度（2021年度を除く25年度分）のインカレ結果を集計したところ、ラウンド別のレース数は次のとおりです。

| ラウンド | レース数（2000〜2025年度・2021年度を除く） |
|---|---|
| 予選（Heat） | 1,561 |
| 敗者復活戦（Repechage） | 1,385 |
| 準決勝（SemiFinal） | 780 |
| 準々決勝（Quarter finals） | 50 |
| 決勝A（Final A） | 305 |
| 決勝B（Final B） | 303 |
| 決勝C（Final C） | 24 |
| 決勝D（Final D） | 4 |
| 決勝E（Final E） | 4 |

決勝Aと決勝Bはほぼすべての年度・種目で設定されている一方、決勝Cが設定された実績があるのは2022〜2025年度、決勝D・決勝Eが設定されたのは2023年度のみです。出場クルー数が多い年度・種目ほど下位の決勝ラウンドが増える傾向がうかがえます。また同じ集計では、決勝Aに並ぶ艇の数は4艇の年度・種目が最も多く、6艇で争われたケースがそれに次いでいます。「決勝」という言葉から連想されるよりも少ない艇数で優勝が決まる場合がある、という点も押さえておくとよいでしょう。年度ごとの詳しい結果は、[年度別結果ページ](../../years/index.html)や[2025年度の結果](../../years/2025/index.html)で確認できます。

## 大会・審判の用語と結果表の記録表記

大会の結果表には、順位のかわりに「DNS」「DNF」「BUW」などの略号や、「棄権」「除外」「失格」といった表記が並ぶことがあります。これらの正式な定義は、JARAの「定義等一覧表（2024年4月1日発効）」で確認できます（出典: [JARA 定義等一覧表](https://jara.or.jp/info/2024/rule202404_define.pdf)）。ここでは、ローイングマニアが収録しているインカレ結果で、こうした記録表記がどれくらい、どの時期に使われているかを整理します。

| 区分 | 表記 | 件数 | 出現年度 |
|---|---|---|---|
| 日本語表記 | 棄権 | 108件 | 2019年度までが中心 |
| 日本語表記 | 艇重量不足 | 13件 | 2019年度までが中心 |
| 日本語表記 | 途中棄権 | 5件 | 2019年度までが中心 |
| 英略号 | DNS | 17件 | 2020年度以降が中心 |
| 英略号 | DNS（棄権） | 6件 | 2020年度以降が中心 |
| 英略号 | DNF | 3件 | 2020年度以降が中心 |
| 英略号 | BUW | 2件 | 2020年度以降が中心 |
| 年度をまたぐ表記 | 除外 | 11件 | 年度をまたいで登場 |
| 年度をまたぐ表記 | 失格 | 8件 | 年度をまたいで登場 |

2019年度までは日本語、2020年度以降は英略号が中心になっています。古い結果と最近の結果を見比べるときは、同じ事情でも表記が変わっている場合がある点に注意してください。件数はクルー×レース単位で、ローイングマニアがJARA公式レース結果を集計したもの（2026-11-11時点）です。前節の決勝ラウンドの集計とは数え方が異なるため、数字を直接比べることはできません。計量に関する話題は[軽量級と減量](../boat-bukatsu-keiryokyu-genryo/index.html)で解説しています。レースの進め方そのものは[ボート競技のルール解説](../boat-kyougi-rule-kaisetsu/index.html)もあわせてご覧ください。

## 用語を覚えたあとに見ると面白いデータ

用語の意味を一通り押さえたら、実際の大会データにも目を通してみると、用語がより具体的なイメージとして頭に入ってきます。

ローイングマニアでは、全日本大学ローイング選手権（インカレ）の2000年度〜2025年度の結果を収録しています。ただし2021年度はJARA側に種目別のレース結果ページが存在しないため、収録は25年度分となっています。この25年度分で集計したレース数は4,416レース、クルー表記に登場した大学数は174大学にのぼります。これだけの大学・レースが、本記事で紹介した種目コードとラウンド表記で記録されているということになります。実際のタイムの水準は[2000mタイムの目安](../daigaku-boat-2000m-time-meyasu/index.html)で確認できます。

どの大学がどの種目で強みを持っているかは、[大学別ページ](../../universities/index.html)から年度別に確認できます。観戦の流れをより詳しく知りたい方は[インカレボート観戦ガイド](../incare-boat-kengaku-guide/index.html)を、通算成績を知りたい方は[インカレボート通算優勝回数ランキング](../incare-boat-yusho-ranking/index.html)をあわせてご覧ください。

## まとめ

大学ボート部の用語は、漕ぎの動作（キャッチ・ドライブ・フィニッシュ・フォワードなど）、艇と道具（ブレード・リガー・シェル艇など）、乗艇ポジションと乗り方（コックス・ストローク・スカル・スイープなど）、種目コード（m1x・w8+など）、レース進行（予選・敗者復活戦・決勝Aなど）に、練習中の号令、大会の記録表記（DNS・DNFなど）を加えた7分類で整理すると理解しやすくなります。特に種目コードとレース進行の表記は、大会結果を読むうえで欠かせない基礎知識です。より詳しいルールを知りたい方は[ボート競技のルール解説](../boat-kyougi-rule-kaisetsu/index.html)を、種目コードの一覧をもう一度確認したい方は本記事の該当表や[種目一覧ページ](../../events/index.html)をあわせてご活用ください。
