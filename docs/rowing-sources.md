# データソース調査記録（ローイング）

## 日本ローイング協会 (jara.or.jp)

- 全日本大学ローイング選手権（インカレ）のレース結果ページ:
  `https://www.jara.or.jp/race/<年度>/<年度>intercollege_<種目コード>.html`
- robots.txt は `Disallow:` なし（全許可）。確認日: 2026-08-14
- HTML構造は2000年度〜2025年度で一貫している（bootstrap系テンプレート）。
  レースごとに `<a name="raceNN"></a>` を起点とするブロックが並び、
  「発艇時刻」「組別」（Heat/Repechage/Quarter finals/SemiFinal/Final A-C、
  年度によっては予選/敗復/準決/決勝の日本語表記）と着順テーブルを持つ。
- クルー表記:
  - シングルスカル（1x）: `個人名<br/><small>(大学名)</small>` 形式。
    **個人名は取得せず、括弧内の大学名のみを抽出**（個人情報配慮）。
  - 複数人艇（2x/2-/2+/4x/4-/4+/8+）: クルーセルに大学名のみが入っており、
    そのまま使用できる。
  - 個人の身長・体重はシート表（`class="collapse"`の折りたたみ行）に入っているが、
    今回は一切パースしない。
- 種目コードは年度により増減する（例: 2000年度は `m2+` あり `w4x+` なし、
  2025年度は逆に `m2+` なし `w4x+` なし・`w8+` あり）。固定の許可リストを
  総当たりし、404を種目未開催としてスキップする設計にした
  （`pipeline/fetch_rowing.py: EVENT_CODES`）。
- 同じ大会ページ配下に「全日本大学選手権」以外の併催大会
  （ジャパンオープンレガッタ=jom8+/jow8+、オックスフォード盾レガッタ=ox/oxm8+）や
  メタページ（et=出漕一覧、tt=タイムテーブル、point=総合得点表、sc=参加人数）が
  存在するが、いずれも大学インカレ本戦のレース結果ページではないため対象外。
- 2026年度（2026-08時点）はまだ大会ページが存在しない（404）。大会は例年
  8月末〜9月開催のため、日次workflowが公開後に自動検知する設計。
- 2021年度はページはあるが種目別レース結果ページが存在しない
  （コロナ禍で大学インカレ規模を縮小 or 中止になった可能性。et/ttのみ存在）。
  → `fetch_rowing.py` はデータ0件の年度は静かにスキップする。
