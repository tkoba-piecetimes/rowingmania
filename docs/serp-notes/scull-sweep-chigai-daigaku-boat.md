# SERP分析メモ: スカルとスイープの違い 大学ボート

調査日: 2026-09-14
検索クエリ: 「スカルとスイープの違い 大学ボート」「スカル スイープ 違い 大学 漕艇」（WebSearch実施）
確認した主な上位ページ: 立教大学ボート部新歓ブログ（ameblo.jp/rubc2020）、note「スイープとスカル、ここが決定的に違う」（note.com/hiroshi32、リオ五輪代表コーチ執筆・有料記事）、Wikipedia「ローイング競技」、東レ滋賀ボート部、N.I.T. RC、関西大学・関西学院大学・京都大学の各部活サイト

## 共通点（検索意図の正解）
1. 「オールの本数」が最も基本かつ共通の切り口：スイープ=1人1本の大オール／スカル=1人2本の小オール、という説明はほぼ全ページで冒頭に置かれている。
2. 艇種の列挙（スカル=シングル/ダブル/クォドルプル、スイープ=ペア/フォア/エイト）と、スイープは偶数人数限定・コックス有無が種目により異なる、という構造説明も共通。
3. 一部の専門的な記事（note）はドライブ局面での水の捉え方の技術差（スイープは前半、スカルは後半が重要）まで踏み込むが、有料の壁があり一般読者には届いていない。

## 上位陣に欠けている要素（差別化点）
1. **大学の部活サイト・個人ブログの寄せ集めで、一次データと接続した記事がない**。「どの艇種が大学ボートで実際にどう使われているか」を、実在の大会結果（歴代優勝校・種目別データ）と結びつけて説明しているページは確認できなかった。
2. **未経験の新入部員がどちらから始めやすいか、なぜそうなのかの説明が薄い**。立教大学ブログは「スイープは高校にないので未経験でも差がつきにくい」という新歓向けの利点に触れるのみで、体系的な解説ではない。
3. **「ボート」単体表記のSERP衝突リスクへの言及・対策が皆無**（当然だが、一般記事は競艇との区別を意識していない）。加えて、初心者が種目区分を理解した後の「観戦」「配属」への接続導線を持つ記事もない。

## 差別化施策（本記事での対応）
- 一次データページ（`/events/`の種目別歴代優勝校ページ、`/universities/`の大学別戦績ページ、`/years/`の年度別結果）への内部リンクを本文中に3本以上設置し、艇種の違いを実際の大会データと接続する。
- 新入部員の種目配属という進路系インサイトに応え、「大学から始めるならどちらが向いているか」を独立したH2で扱う。
- タイトル・全見出し・meta descriptionに「大学ボート」「ボート部」等を明記し、競艇（ボートレース）との誤認を避ける。
